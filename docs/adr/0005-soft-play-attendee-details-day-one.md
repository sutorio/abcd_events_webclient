# Soft-play-style Attendee details for day-one Events

For the first One-offs (silent discos), Attendee data follows a soft-play pattern: adult name and phone; child/baby first name and age; Customer holds email and marketing consent. Per-Event registration profiles (lighter vs safeguarding-heavy) are deferred until toddler-class Terms need richer fields — day one hardcodes this profile rather than building a configurable system.
